# 단기 주가 예측 (1~3거래일)

다음 1·2·3거래일 뒤 종가가 오늘 종가보다 **오를지 내릴지(확률)**, **얼마나 움직일지(예상 등락률과 80% 범위)** 를 예측합니다. 모든 예측 옆에 **워크포워드 백테스트** 결과가 함께 나오며, 예측을 얼마나 믿을지는 이 백테스트가 정합니다. LLM은 쓰지 않습니다(쿼터 소모 없음). 투자 권고가 아닙니다.

## 사용법

처음 쓸 때는 `npm run forecast -- --check`로 자료 출처를 점검하세요. 개발 환경에서는 네이버 접속이 막혀 있어, 지수 경로(`/api/index/{KOSPI|KOSDAQ}/price`)와 일별 시세의 시가·고가·저가·거래량 필드 이름은 실제 응답으로 확인하지 못했습니다(종가·날짜·종목 정보는 기존 수집기가 쓰던 검증된 필드입니다). 점검에서 빠지는 항목이 있어도 예측은 그 특징만 비운 채 동작합니다.

| 방법 | 명령 / 경로 |
| --- | --- |
| 웹 화면 | 분석 방식 **단기 주가 예측** 선택 → 분석 시작 · **오를 확률 순위** 버튼 |
| 한 종목 | `GET /v1/forecast/:ticker?peers=000660,035420&peerCount=20` · `npm run forecast -- 005930` |
| 순위 | `GET /v1/forecast-ranking?exchange=KOSPI&count=30&horizon=1` · `npm run forecast -- --rank --exchange KOSDAQ` |
| 채점 | `GET /v1/forecast-scores` · `npm run forecast -- --score` |
| 합성 벤치마크 | `npm run forecast:synthetic` (네트워크 불필요) |
| 자료 점검 | `npm run forecast -- --check [종목]` — 시세·지수·환율·종목 목록이 실제로 오는지, 시가·고가·저가·거래량 필드가 채워지는지 확인 |

`API_KEY`가 설정돼 있으면 `x-api-key` 헤더가 필요합니다. 한 종목 예측은 동종 대형주 20개 이력까지 받아 학습하므로 처음엔 30초~1분 걸리고, 시세 이력은 30분 동안 캐시되어 다음 종목부터 빨라집니다. 계산은 별도 작업자 스레드에서 한 번에 하나씩 돌아 서버 응답을 막지 않습니다.

## 쓰는 자료

- **종목 일별 시세**(네이버 `m.stock.naver.com` 시가·고가·저가·종가·거래량, 기본 약 3년)
- **시장 지수**(종목이 속한 KOSPI 또는 KOSDAQ)
- **함께 학습하는 종목들**(같은 시장 시가총액 상위 20개 또는 지정한 `peers`)의 당일 평균 등락·상승 종목 비율
- **원/달러 환율**(ECB 기준환율, Frankfurter). 기준환율은 한국 장 마감 뒤에 발표되므로 **하루 늦춘 값만** 씁니다.
- **외국인·기관 순매수**(네이버 투자자별 매매동향, 20일 평균 거래량 대비 당일·5일 순매수). 이 경로와 필드 이름은 개발 환경에서 실제 응답으로 확인하지 못해 필드를 유연하게 인식하며, 받지 못하면 수급 특징만 비우고 결과에 그 사실을 적습니다. `--check`로 실제로 며칠치가 오는지 확인하세요. 합성 시장에서 수급에 심은 신호는 학습됩니다(테스트).

특징(feature) 50개: 1~60일 수익률, 5·20일 변동성, 이동평균 괴리, RSI, 일중 범위·종가 위치, 갭, 거래량 급증, 지수 등락·추세, 베타 조정 초과수익, 120일 고점·저점 거리, 연속 상승·하락 일수, 종목군 평균 대비 상대 강도, 요일·월말/월초, 환율 변동, 외국인·기관 순매수. 모든 특징은 그날 종가까지 알려진 자료로만 계산합니다(테스트로 검증).

## 모델

1. **1단계**: L2 로지스틱 회귀(상승 확률) + 깊이 2 그래디언트 부스팅 트리(비선형·조건부 패턴) + 릿지 회귀(등락률). 등락률은 종목별 최근 변동성 단위로 학습하고 다시 그 종목 변동성으로 환산해, 변동성이 큰 종목은 범위가 넓게 나옵니다.
2. **2단계(스태킹)**: 1단계 확률과 최근 h일·1일 방향(모멘텀/반전 규칙)을 결합합니다. 2단계도 그 시점까지 결과가 확정된 과거 예측으로만 학습하며, 과거 예측이 300개 미만이면 1단계 평균을 그대로 씁니다.
3. **최근 가중**: 학습 표본에 반감기 120거래일의 지수 가중치를 줘 시장 국면 변화(모멘텀↔반전)에 적응합니다. 유효 표본이 1,500개 아래로 줄지 않도록 표본이 적으면 반감기를 자동으로 늘립니다(종목 1개면 사실상 감쇠 없음). 합성 국면 변화 시장에서 1거래일 적중률 52.7% → 55.5%, 안정 시장은 변화 없음.
4. **보정**: 상승 확률은 과거 표본 외 예측으로 Platt 보정하고, 예상 등락률은 표본 외 기울기(0~1로 제한)로 줄입니다. 80% 범위는 표본 외 잔차의 10·90% 분위수입니다. 예측력이 없으면 확률은 과거 상승일 비율 근처로, 예상 등락률은 0 근처로 수렴합니다.

## 백테스트와 신뢰도

- **워크포워드**: 날짜 순서대로 20거래일마다 다시 학습하며, 각 날짜의 예측에는 그 날짜까지 결과가 확정된 표본만 씁니다(미래 정보 누출 방지 테스트 포함).
- **비교 기준**: 동전(50%), 항상 같은 방향(과거 상승 비율), 모멘텀(최근 h일 방향 유지). 적중률, Brier 점수(확률 정확도), 평균 절대 오차(등락률) vs 0 예측, 상위 30% 확신 예측의 적중률을 보고합니다.
- **범위 검증(`range80Coverage`)**: 각 날짜의 80% 범위를 그 날짜 전에 확정된 오차만으로 만들어, 실제 등락이 범위 안에 든 비율을 보고합니다. 80% 근처면 범위가 정직하다는 뜻입니다.
- **우위 판정(`edge`)**: 유효 표본 100개 이상에서 항상-같은-방향 기준을 유의수준 5%로 넘고 Brier 점수도 개선해야 `detected`입니다. 2·3거래일 예측은 기간이 겹치므로 표본 수를 기간으로 나눠 보수적으로 검정합니다.
- **실행 가치(`actionable`)**: 우위가 있고, 예상 등락률이 왕복 거래비용(약 0.25%: 매수·매도 수수료 + 증권거래세)을 넘으며 확률과 같은 방향일 때만 표시합니다.
- **종목별 판단**: 우위 여부는 검정력이 훨씬 큰 종목군 전체 백테스트로 정하고, 개별 종목은 자기 예측 적중률이 자기 기준선(항상 같은 방향)보다 낮으면 우위를 인정하지 않습니다.
- **신뢰도**: 우위가 없으면 `low`(그 방향은 동전 던지기로 보세요), 있으면 확률이 50%에서 10%p 이상 떨어질 때 `high`, 아니면 `medium`.

합성 시장 검증(`npm run forecast:synthetic`): 무작위 보행에서는 모든 기간이 `none`이고, 모멘텀·반전·거래량 신호를 심은 시장에서는 1거래일 예측이 이론적 최대 적중률 근처까지 신호를 찾아냅니다. **실제 시세에서의 적중률은 이 저장소의 개발 환경에서 확인하지 못했습니다**(네트워크 정책상 네이버 접속 불가). 실제 성능은 사용 중인 PC에서 위 백테스트 결과와 채점 기록으로 확인하세요.

## 기록과 채점

모든 예측은 `data/records/forecasts.jsonl`에 남습니다(기준일·종가·기간별 확률·예상 등락·범위·신뢰도·백테스트 적중률). `npm run forecast -- --score`는 이후 실제 종가와 대조해 방향 적중률, 평균 절대 오차, 80% 범위 적중률, Brier 점수를 기간별·신뢰도별로 집계합니다. 제품 시장 분석의 목표가·한 분기 추정은 `data/records/predictions.jsonl`에 남고 `npm run predictions:score`로 실제 EPS·주가와 대조합니다.

### 매일 자동 기록·채점

`.env`에 `FORECAST_DAILY_KST=16:10`을 넣고 서버를 켜 두면, 평일 그 시각 이후 하루 한 번 코스피·코스닥 시가총액 상위 30종목을 예측해 기록하고, 지금까지의 기록을 실제 종가로 채점해 `data/records/forecast-daily.json`에 요약합니다. 실제 시장 성적이 매일 쌓이므로, 몇 주 뒤에는 백테스트가 아닌 실사용 적중률로 신뢰도를 판단할 수 있습니다.

## 한계

- 단기 주가는 대부분 잡음입니다. 실제 시장에서 1~3일 방향 적중률은 50%대 초중반이면 좋은 편이며, 우위가 없는 날·종목이 많습니다.
- 가격은 네이버 일별 종가입니다. 하루 가격제한폭(±30%)을 넘는 변동은 액면분할·병합으로 보고 이전 가격을 보정하지만, 배당락과 ±30% 안쪽의 기업 행위(소규모 유상증자 등)는 조정하지 않습니다.
- 공시·뉴스 이벤트와 미국 증시 야간 등락은 아직 특징에 없습니다(과거 이력을 검증된 형식으로 받을 수 있는 출처를 확인한 뒤 추가할 항목). 수급 자료는 액면분할 전후의 주식 수를 보정하지 않습니다.
