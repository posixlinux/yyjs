# 전략 작업 상태 (2026-09-30)

> **소유권 정정 (2026-09-30):** 사용자가 이후 지시를 다시 바꿨습니다. **앞으로 모든 코드 변경은 Claude가 직접 구현하고, Codex는 로직을 검수(리뷰)만 합니다.** 아래 문단들이 설명하는 "Codex가 구현을 이어받았다"는 과거 지시(자동차 업종 고정 포함)는 이 정정으로 대체됩니다.

투자/자금·하방·유동성/집중도 계산과 검수 지적사항을 반영했습니다. 현재 기능·제약·실행법은 [STRATEGY.md](STRATEGY.md), 검증 결과는 [IMPLEMENTATION_REPORT.md](../IMPLEMENTATION_REPORT.md)를 참고하세요.

**업종 제한 제거 (2026-09-30):** 이전에는 자동차 업종으로 후보를 고정했지만, 이제 후보 티커와 그 업종은 전적으로 사용자가 선택합니다. `config.sector`는 과거 저장된 설정과의 호환을 위해 남아 있는 선택 필드일 뿐 스크리닝에 쓰이지 않으며, 업종별 집중도 한도(`maxSectorWeight`)는 각 후보의 `forecast.sector`를 기준으로 업종마다 독립적으로 적용됩니다. 기존 KOSPI 보통주 범위와 웹 화면의 기존 티커 분석은 그대로 유지됩니다.

첫 Claude 구현은 기본 전략 골격이었고, 이어서 금융 위험 계산·시점/비중 정합성 수정·회귀 테스트·문서화 작업이 있었습니다. 합성 사례로 구현을 검증했으며 실제 데이터의 수익성은 검증하지 않았습니다. 과거의 대기 지시 대신 현재 소스/사용 설명과 위 소유권 정정을 기준으로 작업을 이어가세요.
